# LIB_LISTS

Word lists for games: names, places, random and categorized things. One list per file, `<set>/<list>.txt`; `CATALOG.md` names every file with its line and byte counts.

Rule (owner, 17 Nov 2026): AIs never read the list files. Pick lists by name from CATALOG.md and let game code load them. Local only: never published.
